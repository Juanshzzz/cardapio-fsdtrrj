# Novo Estabelecimento — Cardápio Digital

Repositório de dados e publicação gerado pelo **Cardigital SH** (Template v1.0.0).

## Estrutura Pública
- `cardapio.json`: Dados estruturados e versionados do cardápio (schema v1).
- `metadata.json`: Metadados públicos e versão do template.
- `index.html`: Aplicação pública estática otimizada para dispositivos móveis e SEO.
- `styles.css`: Folha de estilos responsiva do cardápio.
- `app.js`: Script de navegação rápida entre categorias.
- `vercel.json`: Configuração de cabeçalhos e cache para deploy automático na Vercel.
